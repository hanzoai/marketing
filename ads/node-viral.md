# Campaign — Node Viral ("Run a node, jump the line")

**Hook:** "Run a node, jump the line."
**Audience:** waitlist users (Phase 0), prospective operators (Phase 2).
**Phase:** 0 (waitlist hook) → 2 (operator recruitment).
**True claims allowed:** run-a-node = 25 points (biggest single jump); jump the
waitlist. **Earnings (x402/wallet) are `[ROADMAP]` — copy frames them as coming,
not delivered.**

## Variant A — short (waitlist status page CTA)
> Run a node. Jump the line.
> +25 points — the biggest jump there is. Your machine, our cloud, your spot.

## Variant B — social
> The fastest way up the Hanzo waitlist isn't inviting friends.
> It's running a node.
> Spin up hanzod, contribute compute, jump ahead of everyone who just signed up.
> You're not waiting for the cloud — you're becoming it.

## Variant C — the flywheel framing (long)
> Most waitlists make you beg. This one makes you an owner.
> Run a hanzod node and you jump the line today — and when the earnings rail
> opens, the compute you contribute pays you back. Users become infrastructure.
> The cloud grows because you showed up. Run a node, jump the line.

*(Note: only the "jump the line today" is a live promise. "Earnings rail" copy is
conditional — "when it opens" — until x402/wallet ships `[ROADMAP]`.)*

## Variant D — GPU / premium angle
> Got a GPU? It can earn its keep.
> Run a Hanzo GPU node — jump the line now, run confidential (TEE) inference
> later. The premium tier of the network is the hardware you already own.

*(TEE/CC premium tier is `[ROADMAP]` — frame as the plan.)*

## Variant E — competitive/scarcity
> Everyone ahead of you invited three friends. You could pass all of them with
> one command. Run a node. +25. Jump the line.

## Creative concept (assets via hanzoai/studio)
- The neighborhood-view (real, to 10M): a dense field of dots, "you" leaping
  forward past a crowd when the node icon lights up.
- Terminal → line-position counter ticking down ("#4,213 → #1,088").
- A home server / GPU with a subtle "contributing" pulse feeding a cloud.

## Channel note
Primarily **on-product** (waitlist status page, the highest-intent surface) +
X/dev retargeting. This is the hook that quietly recruits Phase-2 supply during
Phase 0. Keep earnings claims honest — line-jump is live, payouts are roadmap.
