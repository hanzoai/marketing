## The honesty rule (applies to every line here)

Only **measured** numbers appear in public copy:
- `0.245 MB per tenant` (papers, measured)
- `1B users / 20 nodes` (papers, measured)
- `28+ social channels` (social.hanzo.ai, real)
- `$4.90 first month` (90% off Pro $49 — arithmetic, real)
- `first 1,000` (the promo cap, server-enforced — real)
- `25% of the compute your code powers` — the author-share *design* `[ROADMAP]`;
  copy must say what it **will** pay, framed as the model, not a delivered stat,
  until the rail ships.

No invented benchmarks. No "10x faster than X." No fabricated latency/throughput.
If Insights hasn't measured it, it doesn't go in an ad.
