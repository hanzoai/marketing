# Campaign — One Binary

**Hook:** "Your AI cloud. One binary. Run it anywhere."
**Audience:** developers, self-hosters, platform/infra engineers.
**Phase:** 0 (organic) + 1 (paid amplification).
**True claims allowed:** one binary; `0.245 MB/tenant`; `1B users / 20 nodes`.

## Variant A — short (X / display headline)
> Your AI cloud. One binary. Run it anywhere.
> No control plane to babysit. No 12-service helm chart. One Go binary.

## Variant B — social (X thread opener)
> We shrank a full AI cloud into a single binary.
> 0.245 MB per tenant. 1B users on 20 nodes.
> Auth, billing, analytics, agents, storage — one process, `//go:embed`'d, runs
> on your laptop or your cluster. Same binary.
> This is what "self-hostable" should have meant all along. 🧵

## Variant C — long (landing / sponsor read)
> Every "AI platform" ships you a diagram: a message queue, three databases, a
> service mesh, and a weekend. Hanzo ships you a binary.
> One process. 0.245 MB per tenant — so 1B users fit on 20 nodes, measured, not
> marketing. Identity, payments, analytics, workflows, agents: embedded, not
> orchestrated. `curl`, run, done. The same artifact scales from your machine to
> production. Your AI cloud. One binary. Run it anywhere.

## Variant D — contrarian (HN / dev-skeptic)
> "Cloud-native" turned into "yaml-native." We disagreed.
> Hanzo is one Go binary — SQLite per replica, no Postgres to run, no nginx, no
> sidecar. 0.245 MB/tenant. It's boring in the way that lets you sleep.

## Variant E — self-host angle
> Own your AI stack. One binary, your hardware, your data.
> Runs on a Raspberry Pi to a GPU rack — same binary. Add a node, get capacity.

## Creative concept (assets via hanzoai/studio)
- A single small file icon (`hanzo`) dragged onto: a laptop, a server, a GPU
  rack, a phone — same icon, same "running" state. "One binary. Anywhere."
- Terminal beauty-shot: one `./hanzo` command, then a clean "cloud up" state.
- Size gag: the `0.245 MB/tenant` number next to a comically large competitor
  architecture diagram.
